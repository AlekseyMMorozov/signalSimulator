## 🔥 ТЕКУЩАЯ ЗАДАЧА
Разработать и реализовать десктопное приложение под виндовс и линукс с графическим интерфейсом, 
предназначенное для симуляции обработки различных радиосигналов.

- модульность

- масштабируемость

## 📋 ОСНОВНЫЕ ПРАВИЛА (12 пунктов)

1. **Размер файлов** при превышении размера файла 300 строк предлагать разделить на два и более - не плодить полотнища, разделять файлы логически оправданно
2. **Один файл за итерацию** — изменяем только один файл за раз.
3. **План до кода** — сначала план и вопросы, ждём подтверждения.
4. **Кодстайл** — PEP8, аннотации типов, обработка исключений.
5. **Логирование** — использовать все уровни (debug/info/warning/error), f-строки.
6. **Русский язык** — комментарии, docstring, ответы — на русском.
7. **Докстринг модуля** — первая строка: путь к файлу, затем описание.
8. **Пустая строка в конце** — каждый файл заканчивается пустой строкой.
9. **Не придумывать** — если сомневаетесь, спросите.
10. **Формат ответа** — см. раздел "Формат ответа" ниже.
11. **Обратная совместимость** — добавлять, а не изменять.
12. **Обработка ошибок** — всегда `try/except` с логированием.
